# Documentation Harmonyz

Objectif produit : **créer un site ou une application permettant de produire un poster représentant une musique**.

| Groupe                                   | Contenu                                                                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [specification](specification/README.md) | L’existant : fonctionnement, architecture, analyse audio, paramètres, limites et environnement de développement.                                       |
| [feature](feature/README.md)             | Ce que l’on veut faire, avec un sous-dossier numéroté par fonctionnalité : objectifs, parcours cibles, évolutions proposées et critères d’acceptation. |
| [rules](rules/documentation.md)          | Conventions de lecture, de création, de référencement et de mise à jour des documents.                                                                 |

Le dépôt contient le parcours import MP3 → aperçu → personnalisation → export PNG, ainsi que la lecture animée en boucle et l’export GIF intégral de la [feature 003](feature/003-mode-anime-musical/README.md). La rétro-ingénierie de ce parcours est conservée dans `specification` ; la suite proposée pour atteindre l’objectif produit est regroupée dans `feature`.
